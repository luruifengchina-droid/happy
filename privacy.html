プライバシーポリシー

最終更新：2026年10月20日

1. このアプリについて

HAPPYは、開発者本人だけが使う個人用のAIアシスタントです。一般の利用者には提供していません。

2. アクセスするデータ

開発者本人が許可した範囲で、次のGoogleのデータにアクセスします。

  • Googleカレンダー：予定の確認、追加、変更
  • Gmail：メールの確認、要約、本人の確認を得たうえでの送信

3. データの使い方

取得したデータは、開発者本人への予定の報告、リマインド、メールの要約のためだけに使います。広告、販売、第三者への提供には使いません。

4. データの保存場所

Googleの認証情報は、開発者本人のコンピューターの中だけに保存します。外部のサーバーには保存しません。要約などの処理のため、データの一部がAIモデルの提供元に送られることがあります。

5. Google API サービスのユーザーデータに関するポリシー

HAPPYによるGoogle APIから取得した情報の使用と移転は、限定的使用の要件を含むGoogle API サービスのユーザーデータに関するポリシーに従います。

6. アクセスの取り消し

アクセスはいつでもGoogleアカウントの設定から取り消せます。

7. 問い合わせ

このアプリについての問い合わせは、Googleの同意画面に表示されるサポート用メールアドレスまでお願いします。

English summary

HAPPY is a personal AI assistant used only by its developer. It accesses Google Calendar and Gmail data only with the developer's own consent, uses it only to provide reminders and summaries to the developer, stores credentials only on the developer's own computer, and never sells or shares the data. HAPPY's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
